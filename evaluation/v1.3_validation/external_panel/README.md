These reference versions were fetched from NCBI and frozen before viewing new
annotation results. See `selection.json` for source URLs, retrieval time and
sequence/reference hashes. The panel was excluded from rule tuning. Database
overlap and reference independence are not established.

The benchmark passes nucleotide-only FASTA to each annotation tool. Reference
products are used only after annotation to assess concordance. Compounds are
excluded from contiguous-coordinate scoring. This panel is a transfer check,
not independent proof of functional accuracy.
