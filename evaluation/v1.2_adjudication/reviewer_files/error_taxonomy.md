# PhageMine error taxonomy for post-unblinding analysis

This taxonomy is descriptive and is applied only after genuine adjudication and unblinding. It does not alter v1.2 annotation or scoring.

`NONE` means no adjudicated error. `OVER_SPECIFIC` means unsupported specificity. `UNDER_SPECIFIC` means an unnecessarily broad label. `WRONG_FUNCTION` means biological conflict. `MISLEADING_DATABASE_HIT` means source evidence led to a misleading assertion. `EVIDENCE_CONFLICT` records incompatible supplied evidence. `TERMINOLOGY_OR_SYNONYM` records a wording problem without biological error. `HYPOTHETICAL_DESPITE_EVIDENCE` records a missed supported function. `INSUFFICIENT_EVIDENCE` records an evidence-limited case. `OTHER` requires an explanatory rationale. Reviewers should retain the original evidence source, identifier, score, threshold, and unmodified value in analysis tables.
