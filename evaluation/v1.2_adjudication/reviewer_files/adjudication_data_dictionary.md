# Blinded adjudication data dictionary

`case_id` and `blinded_unit_id` are stable anonymous identifiers (`FB0001`...). `matching_mode` is the frozen exact or relaxed stratum. `genome`, `reference_locus`, coordinates, strand, and reference product identify the frozen evaluation locus. `prediction_A_*` and `prediction_B_*` are neutral labels; their tool mapping is withheld from reviewers. `*_evidence_raw` preserves the archived evidence JSON/GFF attributes; values are not newly interpreted. These raw objects may contain existing product, functional state, confidence, source/database identifiers, hit/domain/profile fields, scores, thresholds, reasoning, and provenance values. `*_evidence_source` describes the archived file class. `existing_evidence_note` states that no new search or interpretation was performed.

Reviewer fields are blank in the template: `final_judgment` (alias `adjudication_class`), `evidence_basis`, `uncertainty`, `evidence_supports_prediction`, `evidence_strength`, `specificity_appropriate`, `conflicting_evidence`, `preferred_product_name`, `error_category`, `reviewer_rationale` (alias `reviewer_notes`), `reviewer_id`, `review_timestamp`, `reviewer_confidence`, and `reviewer_comment`. `review_required=YES` is an operational flag, not a judgment. Controlled vocabularies are listed in `Decision_Definitions` and enforced by workbook dropdowns. `reviewer_rationale` must justify the category using supplied evidence. Original raw values must not be edited.
