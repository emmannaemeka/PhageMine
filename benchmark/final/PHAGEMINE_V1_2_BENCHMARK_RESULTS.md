# PhageMine v1.2 benchmark results

The authoritative automated output files are in
`automated_benchmark_results/`. The automated adjudication completed all 689
units before unblinding. It produced 213 resolved/scored decisions and 476
UNRESOLVABLE decisions.

The observed utility bounds are PhageMine 0.107692–0.869231 and Pharokka
0.004487–0.986538. The observed lower-bound difference is +0.103205 against the
prespecified +0.05 margin. Because 476/689 cases were unresolved, this is a
descriptive bound, not a confidence-interval-based superiority result.

The automated unsupported-specificity difference is 0.000000 descriptively;
this means no case was assigned to that category by this rule set and does not
establish absence of true unsupported specificity.
