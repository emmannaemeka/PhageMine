# PhageMine v1.2 benchmark methods

The benchmark was constructed from the frozen seven-genome v1.2 evidence and
the published structural comparison. Stable blinded identifiers FB0001–FB0689
were assigned to the review units. Evidence packets retained the original
products, reference products, coordinates, scores, thresholds, provenance, and
other evidence already generated by the frozen pipeline.

The utility definition and margins were frozen before adjudication. The
sequence was:

```text
frozen benchmark construction
  -> stable blinded FB identifiers
  -> evidence packet generation
  -> utility definition frozen
  -> checksum freeze
  -> automated evidence adjudication while blinded
  -> automated adjudication freeze
  -> leakage audit
  -> tool-key access
  -> unblinding
  -> prespecified descriptive pipeline
  -> post-unblinding error analysis
```

The adjudicator used deterministic evidence rules: exact normalized agreement
and the frozen explicit synonym were accepted; compatible broader assertions
were marked TOO_GENERAL; family-only, weak, partial, conflicting, or otherwise
ambiguous evidence remained UNRESOLVABLE; non-informative reference products
were NOT_EVALUABLE. This was `AUTOMATED_EVIDENCE_ADJUDICATION`, not independent
human expert adjudication. The original human workflow and confidential key
remain separate and unchanged.
