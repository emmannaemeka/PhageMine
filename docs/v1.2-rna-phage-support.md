# v1.2 RNA-phage support

RNA annotation is selected explicitly with `--molecule-type rna`; the default
remains DNA for backward compatibility. RNA does not use the DNA PHANOTATE,
Pyrodigal, or Prodigal-gv consensus profile. It uses the dedicated
`pyrodigal_rv` provider (`pyrodigal-rv` 0.1.0, when installed) and policy
`RNA_PYRODIGAL_RV_PRIMARY_V1`.

Pyrodigal-rv is a native Python `ViralGeneFinder` implementation. Its raw
provider records, translation metadata, segment identifier, input checksum,
and normalized 1-based inclusive coordinates are preserved under
`gene_calls/raw/pyrodigal_rv.*`. Small, overlapping, and edge CDSs are not
removed by PhageMine. Confidence remains rule-based and uncalibrated.

The current single-genome workflow preserves one segment identity in all
machine-readable traces and manifests. Segmented FASTA support is represented
by the provider interface and segment-local coordinates; multi-record FASTA
annotation requires an explicit segment-aware orchestration layer and is not
silently concatenated. A missing Pyrodigal-rv installation is a hard,
actionable provider error; no DNA caller fallback occurs.

Functional evidence uses the resulting RNA protein set when databases are
available. Lack of a database hit is not treated as evidence that an RNA CDS
is invalid. RNA database coverage and translation-table inference are
limitations requiring review.
