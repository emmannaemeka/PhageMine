# PhageMine v1.2 biological feature freeze

This freeze records the implemented biological architecture at commit
`9ebafeab264abcbdb7cffcd1c6b606b9df6e66cd`.

DNA providers are PHANOTATE, Pyrodigal, and Prodigal-gv. DNA reconciliation is
the generic v2 engine (`algorithm_version=1.0`); adjudication is observational
(`GeneModelDecision`); selection is conservative consensus policy `1.0`, with
`phanotate-only` remaining the default CLI policy. The reconciliation overlap
policy remains 30 bp/0.1 reciprocal or 0.5 reciprocal, and evaluation
thresholds are not changed here.

RNA uses Pyrodigal-rv 0.1.0 and policy `RNA_PYRODIGAL_RV_PRIMARY_V1`.
Explicit `--molecule-type rna --segmented` processes each FASTA record
independently with segment-local coordinates and never concatenates segments.
Functional evidence sources remain Pfam, VOGDB, Swiss-Prot, PHROGs MMseqs2 and
PHROGs PyHMMER where available; confidence remains uncalibrated.

The development suite currently reports 254 passed and 10 deselected. The
historical v1.1 sentinel audit was read-only; no v1.2 caller was run against
the frozen genomes. The frozen publication benchmark has not been rerun
against this v1.2 implementation. Any future change to caller set, reconciliation,
selection, RNA policy, or thresholds requires a post-freeze defect record.
