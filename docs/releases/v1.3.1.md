# PhageMine v1.3.1

First release intended for publication to PyPI.

This release adds the PyPI publishing workflow, refreshes the Bioconda recipe,
and surfaces packaged install paths in the README. Annotation, gene calling,
and evidence handling are unchanged from v1.3.0.

## Install

After PyPI publication, install with `pip install phagemine`.
See [CHANGELOG.md](https://github.com/emmannaemeka/PhageMine/blob/v1.3.1/CHANGELOG.md)
for changes and the
[installation guide](https://github.com/emmannaemeka/PhageMine/blob/v1.3.1/docs/installation.md)
for external tools and databases.
