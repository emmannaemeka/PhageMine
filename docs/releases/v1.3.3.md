# PhageMine v1.3.3

Adds annotation reliability checks to fresh single-record DNA runs:

- Coding capacity counts overlapping CDS bases once and flags values below 85%
  for review. Low density alone is not proof of an alternative genetic code.
- Native Pyrodigal-gv alternative-code observations and CDSs shorter than 100 nt
  receive review tables. Final PHANOTATE calls and translations remain unchanged.
- Optional `--reference-genbank` files support nucleotide screening, adjustable
  coverage/identity thresholds, distribution plots and gene-boundary review.
- No VIRIDIC dependency or change to the existing whole-genome similarity method.

Reference checks require BLASTN and supplied annotated GenBank files. They do not
verify ICTV reference status or automatically transfer annotations. Short genes
missed by both callers remain undetected. See the
[annotation reliability guide](https://github.com/emmannaemeka/PhageMine/blob/v1.3.3/docs/annotation-reliability.md).

This release also connects verified automated GitHub releases to PyPI publication
with exact-tag and successful-check validation. PyPI and Bioconda availability
must be confirmed independently; a GitHub tag alone does not update registries.

Install from PyPI after publication:

```bash
python -m pip install --upgrade phagemine==1.3.3
```

External executables and annotation databases must still be installed separately
for PyPI installations. Bioconda includes external tool dependencies once its
updated recipe has been built and published.
