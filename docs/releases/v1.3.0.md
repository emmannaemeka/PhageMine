# PhageMine v1.3.0

This stable release includes the updated multi-resource annotation and naming
rules, evidence review, RNA feature support, reproducibility bundles and GUI fixes.
PHANOTATE gene calling remains unchanged.

## Install

Follow the [installation guide](https://github.com/emmannaemeka/PhageMine/blob/v1.3.0/docs/installation.md).
The release provides a Python wheel, source distribution and SHA256 checksums.
External analysis executables and the six databases are installed separately.
This GitHub release does not establish publication on PyPI or Bioconda.

## Validation

Publication requires successful checks on the exact release commit: the Linux,
Intel macOS and Apple-silicon macOS package test matrix, fresh wheel installation,
GUI tests, Linux external-tool integration and container execution. The attached
release-validation.json identifies the successful runs and package dependencies.

The latest fresh ten-genome all-six-resource benchmark reproduced all 978
reviewed annotation rows. Naming changes recovered 20 names consistent with exact
reviewed records, without changing gene coordinates or protein sequences.
The sequence-bound Prokka review includes 154 exact reviewed sequence cases and
120 unresolved cases. Confidence remains rule-based and uncalibrated; overall
accuracy superiority over Prokka or Pharokka has not been demonstrated.
