# PhageMine v1.4.1

**Gene-start accuracy.** A canonical-initiator guard now runs after start refinement and before evidence searches. When a rare table-11 initiator (CTG/ATT/ATC/ATA) was chosen on Shine-Dalgarno/spacing evidence alone, the CDS moves to the unique canonical Prodigal-GV start for the same strand and stop. Starts anchored by N-terminal homology or translational coupling are kept, as are same-strand overlaps of 100 nt or more (for example Rz/Rz1 spanins). Every decision is recorded in `gene_calls/initiator_guard.json`, and no reference annotation is used. On the eight-genome benchmark with all databases, exact CDS boundaries rose from 765 to 773, with no exact match lost. The held-out OP373729.1 went from 70 to 72 and PX787804.1 from 83 to 84, and all 44 acceptance checks passed.

**Product names.** Functional product names that contained a locus designation (for example "baseplate wedge protein gp25") were exported as "hypothetical protein". The descriptive name is now kept, and "probable" is written as "putative". Named products on the benchmark genomes rose from 452 to 492 of 978.

**Manual curation package.** `final_annotation_package/<genome>_gene_curation.tsv` has one row per CDS and 55 fields: coordinates, codons, products, functional state, best PHROGs/VOGDB/Swiss-Prot hits with descriptions and statistics, domains, gene neighbourhood, RBS and start-selection evidence, review actions, and full nucleotide and protein sequences. The same table is the first `Gene_Curation` sheet of the reviewer workbook, and `README_CURATION.txt` documents the package.

The release also contains the previously unreleased structural-accuracy work:
- Prodigal-GV-supported start selection with synchronized table-11 exports
- RBS-aware start refinement and genome QC
- spanin subtype normalization
- partial-CDS export repair with evidence-gated overlap recovery
- CDS confidence tiers, submission-metadata support and reviewer export packages

Reference starts are not experimentally established, so agreement with RefSeq measures concordance, not biological truth.
