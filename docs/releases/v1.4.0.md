# PhageMine v1.4.0

Annotated GenBank output is available at `genbank_submission/genome.gbk` without table2asn. Supported computational product names and protein translations are retained. Submission readiness remains a separate validation result.

This release bounds LOCUS names to 16 characters while retaining full accessions, supports explicitly supplied topology, and writes `final_gene_models.tsv` for cross-output checks. Unknown topology is not inferred. A regression fixture checks 72 PHANOTATE calls on PZ583544.1 for gene counts, coordinates, strands, translations, and product-name preservation; this establishes export consistency, not biological accuracy.

CI retains Linux, Intel macOS, and ARM macOS coverage, using supported macOS 15 runners. Publication is gated by the existing verified-release and PyPI workflows.
