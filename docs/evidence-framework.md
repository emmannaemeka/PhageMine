# Evidence framework

PhageMine keeps three outputs separate. Functional confidence describes how well a proposed interpretation is supported. Biological interest ranks whether a protein merits investigation. Evidence diversity counts distinct supporting modalities; it is not a confidence score.

Evidence is classified as experimentally established, curated database-supported, computational prediction, weak inference, or hypothesis requiring validation. Each record retains its source, database version, parameters, status (real or mock), supporting/contradicting role, and modality. A high-interest, low-confidence candidate is valid: it is an uncharacterised protein worth testing, not a claimed function.

Novelty means unusualness, not importance. Context generates hypotheses, not proof. Missing hits are distinguished from unavailable searches. Contradictions and plausible alternatives are reported alongside support.
