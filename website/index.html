PhageMine brings bacteriophage genome annotation, functional evidence and comparative genomic context into one workflow.

Developed by Nnaemeka Emmanuel Nnadi for researchers working in phage biology, viral genomics and bioinformatics.

GET STARTED

Install, prepare, analyse.

Python 3.10 or later. Release 1.3.1 on PyPI.

Install with pip

pip install phagemine
phagemine --help

Install external analysis tools separately. Follow the installation guide for PHANOTATE, HMMER, MMseqs2, DIAMOND, Mash and BLASTN.

Or use Bioconda

conda create -n phagemine -c conda-forge -c bioconda phagemine
conda activate phagemine

Bioconda supplies external tools; its available version may differ from PyPI. Check the Bioconda package listing.

Prepare the databases

phagemine databases install --all
phagemine doctor

The six resources are PHROGs, VOGDB, Pfam, Swiss-Prot, PMFDB and INPHARED. Downloads total approximately 3.4 GiB; allow 15–20 GiB free for preparation.

Database downloads do not install missing executables. Check that the required capabilities report READY before a full-evidence analysis.

Analyse a genome

phagemine run genome.fasta --output results/genome --threads 8

Open results/genome/report.html to review the results.
