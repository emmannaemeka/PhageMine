# Independent evidence-engine validation

This directory contains a prospective protocol for validating the merged
next-generation evidence engine. It is a design and freeze record only. No
validation panel has been selected, downloaded, annotated, or scored here.

The five development genomes and the seven v1.2 reference genomes are
explicitly excluded. The protocol must be reviewed and frozen before any
validation outputs are observed.

Workflow: panel selection and exclusions → reference-standard assembly →
frozen tool/database manifests → blinded evidence packets → independent
adjudication → locked analysis → unblinding and reporting.

Validation is intended to measure reliability, transparency, uncertainty
calibration, and biological interpretability. It is not designed as a claim
of software superiority.

The protocol review must approve the sample-size scenarios, reference tiers,
clustering rules, failure criteria, and claim language before panel selection.
PR review is not authorization to execute validation.
